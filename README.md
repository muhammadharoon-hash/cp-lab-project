Simple Banking System
A lightweight, command-line based banking application that provides core banking operations. Designed for learning purposes and demonstrates fundamental banking concepts without a graphical interface.
Features

Account Management — Create and manage bank accounts
Deposits — Add funds to accounts
Withdrawals — Withdraw money with balance verification
Balance Inquiry — Check current account balance
Fund Transfers — Transfer money between accounts
Transaction History — View all transactions for an account
Account Holder Information — Store and retrieve customer details
Overdraft Protection — Prevent withdrawals exceeding balance

Core Operations
1. Create Account → Generate unique account number
2. Deposit Money → Add funds to account
3. Withdraw Money → Remove funds (with balance check)
4. Transfer Funds → Move money between accounts
5. Check Balance → View current balance
6. View History → See all transactions
7. Close Account → Deactivate account
